// 03 — for developers and agents

Secrets in your terminal, never in .env files.

zv talks to the Zvault app on your Mac. The app asks you to approve, then hands over only what the command needs. Output is masked.

  • zv run starts a command with secrets in its environment
  • zv read or zv copy one secret
  • zv agent pair connects an AI agent that you approve
