01 · Encrypt

Sealed on your device.

Priya shares the prod password. Zvault seals it on her Mac with a fresh random key. 

key = random(32 bytes)
ct  = xchacha20poly1305(key, item)
upload(ct)   // the key stays here
02 · Store

Even we can't see through.

The server keeps ciphertext, a view counter and an expiry. No key, so no plaintext. 

stored.ct       = 412 bytes
stored.views    = 1
stored.key      = — (not ours to hold)
03 · Share

The key stays after the #

Browsers never send the URL fragment in a request. Our logs only see the part before it. 

location.hash  // "#k3v9…id.Xq7…key"
// read by the page, never sent over HTTP
04 · Verify

A code only they receive.

Six digits to sam@acme.dev, valid 10 minutes. Then his browser decrypts it locally. 

verify(sam@acme.dev, 482917)  ✓
plain = open(key_from_hash, ct)  // here
05 · Expire

One view. Then nothing.

The link is spent. The server never saw a thing, and now there's nothing left to see. 

views_left = 0   // link expired
server.saw  = ciphertext only

// 03 — for developers and agents

Secrets in your terminal, never in .env files.

zv talks to the Zvault app on your Mac. The app asks you to approve, then hands over only what the command needs. Output is masked.

  • zv run starts a command with secrets in its environment
  • zv read or zv copy one secret
  • zv agent pair connects an AI agent that you approve
